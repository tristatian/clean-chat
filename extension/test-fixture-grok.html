What is PKCE and why does a static site need it?

What PKCE does

PKCE lets an app that cannot keep a secret run the OAuth authorization-code flow safely. The app proves it started the login with a one-time secret it generated itself.

  • Generate a random verifier and hash it.
  • Send the hash; keep the verifier.
What happens when the access token expires?

Access tokens last about an hour. Use the refresh token to get a new one without another login.
