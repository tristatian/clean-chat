What PKCE does

PKCE lets an app that cannot keep a secret run the OAuth authorization-code flow safely. The app proves it started the login with a one-time secret it generated itself.

  • Generate a random verifier, hash it with SHA-256, base64url-encode the digest.
  • Send the hash with the authorize request; keep the verifier in the browser.
  • Trade the returned code plus the verifier for tokens.

An attacker who intercepts the code cannot redeem it without the verifier.
What happens when the access token expires?

Access tokens last about an hour. Use the refresh token to get a new one without another login, and store the newest refresh token each time.
